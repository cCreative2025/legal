# 하모(Hamo) — 계정·데이터 삭제 방법

하모 사용자는 본인의 계정과 모든 데이터를 다음 두 가지 방법으로 삭제할 수 있습니다.

---

## 방법 1. 앱 내에서 직접 삭제 (권장)

가장 빠르고 즉시 처리됩니다.

1. 하모 앱 실행
2. **설정** 탭 → 화면 아래 **"회원 탈퇴"**
3. 안내를 확인하고 **"탈퇴"** 탭

→ **즉시** 본인의 모든 데이터가 영구 삭제되고 자동 로그아웃됩니다. 되돌릴 수 없습니다.

---

## 방법 2. 이메일 요청

앱에 접근할 수 없는 경우 아래 이메일로 요청해 주세요.

**이메일**: [support@loungees.net](mailto:support@loungees.net)

요청 시 다음 정보를 포함해 주세요.
- 로그인에 사용한 Apple·Google 계정 이메일
- 앱의 표시 이름

→ 본인 확인 후 **영업일 기준 7일 이내** 처리됩니다.

---

## 무엇이 삭제되나요?

- 계정 정보(표시 이름, 로그인 식별자, 이메일)
- 올린 악보 파일과 곡 정보, 송폼, 필기, 메모·댓글
- 내가 만든 팀과 그 팀의 세션·객원 링크 (팀원들도 더 이상 볼 수 없습니다)
- 다른 팀의 멤버십

백업에 남은 사본은 최대 30일 안에 삭제됩니다. 법령이 보관을 요구하는 접속 기록은 해당 기간 보관 후 삭제합니다.
