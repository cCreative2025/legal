# 쉿 (Shh) — 지원 / Support

그림마다 다른 서랍이 열리는 사진·영상·링크 금고, 그리고 조용한 쉿 타이머.
A quiet vault for photos, videos and links — every pattern opens a different drawer.

## 자주 묻는 질문

**그림(패턴)을 잊었어요.**
잠금 화면의 '그림이 기억나지 않아요'를 누르고, 서랍을 만들 때 적어 둔 복구 문구 9단어를 입력하세요. 그 뒤 새 그림을 정하면 됩니다. 그림과 복구 문구를 모두 잃으면 운영자도 열어 드릴 수 없습니다.

**서랍은 어떻게 여러 개 만드나요?**
잠금 화면에서 새 그림을 그리면 새 서랍이 생깁니다. 그림마다 다른 서랍이 열리며, 앱은 서랍이 몇 개인지 기록하지 않습니다.

**폰을 바꾸면요?**
현재 버전은 서랍을 기기 안에만 보관합니다. 기기를 옮기기 전에 필요한 사진은 '꺼내기'로 사진 보관함에 옮겨 두세요. iCloud 암호화 백업은 다음 버전에서 제공할 예정입니다.
